# Build Something Real - The Real-World AI Project Playbook

A free beginner-friendly AI project guide by productwithsasi.

## Included
- Responsive landing page in consistent blue (#0A66C2) and pale blue (#EDF5FF).
- Downloadable 20-page PDF educational guide.
- Six copy-ready Markdown templates in the templates folder.
- AI prompts and official resources for models, voice agents, design, hosting and development.
- One fixed social CTA: Connect on LinkedIn. No Instagram floating buttons.

## Local development
Run a local HTTP server: python3 -m http.server 8080
Then visit http://localhost:8080. Templates load using fetch, so do not open using file://.

## Deploy on Vercel
1. Import this repository.
2. Framework Preset: Other.
3. No build command. Set output directory to the project root if prompted.
4. Deploy and enable Git integration for automatic updates.

## Notes
Independent educational resource. Free tiers, model availability and prices change; verify official docs. Voice frameworks may be free while inference, hosting and phone calls cost money. Never claim to have performed external actions without confirmation from a real integration.
